# Storyfy - Textos para App Store

## Nome
Storyfy

## Subtitulo
Suas fotos viram histórias

## Texto promocional
Crie uma retrospectiva bonita do mês anterior com curadoria de fotos e legenda no seu estilo.

## Descricao curta
Storyfy transforma as melhores fotos do mês em uma história pronta para revisar, editar e compartilhar.

## Descricao completa
Storyfy ajuda você a reviver seus meses sem passar horas procurando fotos.

Escolha o mês, deixe o app organizar os principais momentos e revise uma história com fotos selecionadas, temas detectados e uma legenda editável. Você também pode conectar o Instagram para o Storyfy aprender o padrão das suas legendas anteriores e escrever de um jeito mais parecido com você.

Recursos:
- Curadoria automática das fotos do mês.
- Agrupamento por momentos, lugares e contexto.
- Legendas com IA e fallback local quando a API não estiver disponível.
- Integração opcional com Instagram para aprender seu estilo.
- Integração opcional com Calendário para enriquecer os momentos.
- Edição manual antes de compartilhar.
- Lembrete mensal para criar a história do mês anterior.

Planos:
- Free: até 2 legendas com IA por mês.
- Plus: para quem cria retrospectivas mensais com mais liberdade.
- Creator: para quem cria histórias com frequência.

O Storyfy não publica nada automaticamente. Você sempre revisa o conteúdo antes de compartilhar.
